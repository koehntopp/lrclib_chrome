**Quick Lyrics** – Songtexte schnell finden, über mehrere Quellen hinweg.

Du suchst einen Songtext? Ein Klick auf das Extension-Icon öffnet ein Suchfeld, das deinen letzten Suchbegriff bereits vorschlägt. Mit dem Zwischenablage-Button fügst du bei Bedarf den kopierten Text ein – automatisch ausgelesen wird nichts, du behältst die Kontrolle.

**Durchsucht auf Wunsch:**
- lrclib.net
- AZLyrics
- Genius
- Google (`lyrics <Suchbegriff>`)

So findest du auch dann einen Treffer, wenn eine einzelne Datenbank den Song nicht führt.

Keine Datenübertragung an Dritte, keine Tracker – alle Daten bleiben lokal im Browser.
